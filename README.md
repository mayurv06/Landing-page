# Triply — AI Trip Planner (Landing Page)

This is a mobile-first, production-ready static landing page prototype for an AI-powered Trip Planner. It includes a hero, features, how-it-works steps, testimonials, use cases, and a small demo modal that simulates generating an itinerary.

Quick start

1. Open the directory in your editor.
2. Serve the folder with a static server. Example using Python:

```bash
python -m http.server 8000

# then open http://localhost:8000 in your browser
```

Or with Node.js `serve`:

```bash
npx serve . -l 5000
```

Files
- index.html — main landing page
- styles.css — styling and responsive layout
- script.js — small UI interactions and mock AI demo
